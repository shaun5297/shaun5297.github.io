# Yidong Shen — Portfolio

Bilingual personal portfolio for autumn recruitment, focused on computer vision, embodied intelligence, and brain–computer interfaces.

## Local preview

Open `index.html` with a static web server. The site has no runtime dependencies or build step.

## Content policy

- Public contact: `yidong0501@gmail.com`
- Current GitHub avatar is used as the portrait.
- Project claims are limited to the supplied résumé, paper, project documents, and public repositories.
- Pending internship details are intentionally not presented as finalized experience entries.
- Human-subject photos, coworker faces, and screenshots exposing local network details are not published.
